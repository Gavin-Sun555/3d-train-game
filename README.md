# 3D Train Mode · 西雅图有轨电车建设、规划与模拟驾驶

基于 **Godot 4.7 Forward+** 构建的独立 3D 有轨电车建设规划与模拟驾驶游戏。覆盖西雅图市中心 **Pike Place Market — Westlake Center — Denny Triangle — South Lake Union（联合湖滨）** 约 `1 km × 2 km` 真实街区路网。

## 快速启动

```bash
# 启动游戏
make run

# 使用 Godot 4 编辑器打开项目
make editor

# 重新从 ../2d-train-game 提取路网与 14 款电车数据
make data
```

## 核心功能

### 1. 扩大版西雅图核心走廊地图（`980m × 2010m`）
- 包含 **428 个真实路口节点、576 段可铺轨街道**、近 600 栋带三维壁柱/退台/檐口与 3D 室内视差房间的建筑，以及 **Amazon The Spheres、威斯汀双子塔、Westlake Center、五大道单轨列车、丹尼公园与联合湖水岸**。

### 2. 轨道建设与线路规划（铺设后道床类型永久固定，运行中不可切换）
通过顶部导航栏（或 `Tab` 键）在三大模式间切换：
- **🛠 1. 建设轨道模式（静态鸟瞰）**
  - **5 种施工期可选道床**（一旦铺设即绑定在该街道段，运营驾驶时无法切换，仅可在建设模式改建）：
    `独立工字草皮` · `柏油槽型嵌轨` · `齐平绿茵草皮` · `花岗岩专用道` · `碎石工字枕木`
  - 支持**单击单段街道铺轨**、**连点两路口 Dijkstra 最短路自动铺轨**、**建造精细 3D 车站（`R` 切换左右侧站台）**、**拆除车站/轨道**，以及 `F5 / F9` 存档读写。
- **🗺 2. 规划线路模式（静态鸟瞰）**
  - 依次点击地图上已建成的车站串联站点（支持**双向往返折返线**与首尾闭合**环线**），实时预览线路走向。
  - 从 **14 款现代与古典电车库**（支持 `全部 / 现代电车(8) / 古典老车(6)` 筛选）中选配车型、设定配车数（`1~8 辆`）与编组节数（`1~4 节`）。
- **🚋 3. 运行与驾驶模式**
  - 所有开通线路自动派车运营、跟车防追尾、到站开门上下客、终点自动换向折返。
  - 按 `F` 切换跟踪任意列车，按 `Q` 随时在 **AI 自动运营** 与 **玩家手动驾驶** 间切换。

### 3. 随机客流模拟与 5 档乘客生成速度（`P`）
- 支持 **`1档 稀少 / 2档 较少 / 3档 标准 / 4档 繁忙 / 5档 高峰`** 五档客流生成速度实时调节。
- 3D 乘客从站台无障碍坡道进站排队候车；电车靠站开门并伸出踏步渡板后，到站乘客从开放车门走出下坡离站，候车乘客越过安全黄线登车并呈现在 3D 车厢座位与立柱旁。

### 4. 14 款精细内外饰电车库 + 5 机位视角（含车厢内部与车门特写）
- **8 款现代低地板电车**：西门子 S700、Inekon 12 Trio、中车长客苏州电车、中车株机海珠电车、阿尔斯通 Citadis X05、西门子 Avenio、宇都宫 HU300 雷都线、广岛电铁 5200形 APEX。
- **6 款 1950 年代前经典老电车**：1936 PCC 流线型电车、1935 大连 3000型、1930 里斯本 Remodelado、1923 新奥尔良 900型、1924 柏林 T24型、1942 广岛电铁 650形（配复古铁艺排障器、单圆头黄铜大灯、双层采光天窗顶与折叠木门）。
- **精细车厢内部与 5 大视角**：人体工学座椅/复古木长椅、立柱扶手、顶部拉环吊手、挡风玻璃隔屏、车内电子报站屏、外摆塞拉门 + 伸缩踏步渡板；支持 `1 驾驶室`、`2 追尾外景`、`3 车厢内部乘客视角`、`4 车门上下客特写`、`5 鸟瞰全局`。

### 5. 精细 3D 车站设施
- 铺装花岗岩站台、两端无障碍斜坡、不锈钢与钢化玻璃护栏、弧形悬挑玻璃雨棚、自动售票机（TVM）、刷卡验票立柱、电子到站显示屏、双面线路图灯箱、实木候车长椅与立式站名灯箱塔。
